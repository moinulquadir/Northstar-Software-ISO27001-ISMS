# PR-001 Joiner / Mover / Leaver Procedure

**Owner:** IT Manager | **Frequency:** Per personnel event

1. HR submits the personnel event.
2. Manager confirms role and required access.
3. IT creates, changes, or disables the identity using the approved request.
4. MFA and baseline security controls are applied.
5. Assets and credentials are assigned or recovered.
6. Completion is recorded in the ticket.

**Records:** HR event, access request, provisioning/deprovisioning ticket, asset return record.
