# ISMS Scope and Boundary Matrix

| Area | In Scope | Rationale |
|---|---|---|
| SaaS production | Yes | Core customer service |
| AWS infrastructure | Yes | Hosts production service |
| Corporate endpoints | Yes | Access in-scope information |
| Secure SDLC | Yes | Develops production software |
| Customer support | Yes | Handles customer information |
| Critical suppliers | Interface managed | Material dependency |
| Customer-owned networks | No | Outside organizational control |
| Supplier internal operations | No | Managed through supplier assurance |

Scope is reviewed after material organizational, technology, legal, customer, or supplier change.
