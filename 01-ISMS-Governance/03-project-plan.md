# ISO 27001 ISMS Project Plan

| Phase | Deliverables | Owner | Exit Criteria |
|---|---|---|---|
| Initiation | charter, stakeholders | COO | sponsor approval |
| Context & Scope | scope, boundaries | ISMS Manager | scope approved |
| Assets & Risks | inventory, risk register | ISMS Manager | owners assigned |
| Treatment | treatment plans, SoA | Risk Owners | decisions approved |
| Implementation | policies, procedures, controls | Control Owners | evidence available |
| Audit | internal audit, findings | Internal Auditor | report issued |
| Improvement | CAPA, management review | COO/ISMS Manager | actions assigned |
| Readiness | gap assessment | ISMS Manager | open gaps documented |
